# Code availability

The STACKWISE source code used to construct, validate and package the empirical benchmark and to run the publication experiments is maintained at:

- Repository: https://github.com/KuznetsovKarazin/stackwise-iot-benchmark
- Public software release/tag: `v0.1.62`
- Frozen benchmark dataset: https://doi.org/10.5281/zenodo.21937093

The repository does **not** redistribute the raw upstream measurement archives. Their identifiers, licences and provenance are recorded in `datasets/registry.yml`, `DATA_LICENSES.md` and the dataset cards under `docs/DATASET_CARDS/`.

The frozen benchmark data are distributed separately through Zenodo as **STACKWISE Empirical Evidence Benchmark v1.0.0**. The software repository is licensed under Apache-2.0; STACKWISE-authored benchmark material is licensed under CC BY 4.0.

For manuscript use, the recommended statement is:

> The custom Python code used to construct and validate the STACKWISE benchmark and reproduce the Paper B decision-readiness analyses is openly available at https://github.com/KuznetsovKarazin/stackwise-iot-benchmark (release v0.1.62). The frozen benchmark dataset is available from Zenodo at https://doi.org/10.5281/zenodo.21937093. Raw upstream measurement archives are not mirrored in the code repository and remain available from their original repositories under their respective licences.

# Paper B external-validation public results

This directory contains compact, publication-relevant outputs for the STACKWISE Paper B external-validation campaign. Large third-party raw inputs are intentionally not redistributed. Their DOI/source identifiers and checksums are recorded by the protocol/manifests.

The audit files contain four anonymised independent primary raters (A-D). Original returned CSVs and free-text rationales are not published here.

The benchmark dataset remains STACKWISE Empirical Evidence Benchmark v1.0.0; these files are validation results for the methodology paper and do not modify the benchmark release.
